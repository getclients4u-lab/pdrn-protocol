# The PDRN Sandwich & Stack Planner

### Exactly what goes on your face, in what order, at what time — with the do-not-mix rules

---

## The core move: the PDRN Sandwich

Five layers. Order matters. Water first, oil last. PDRN in the middle, never alone.

```
      ☀️ MORNING                          🌙 NIGHT (PDRN night)
┌──────────────────────┐          ┌──────────────────────────┐
│ 1. Rinse / cleanse   │          │ 1. Gentle cleanse         │
│ 2. Hydrating toner   │          │ 2. Hydrating toner/essence│
│ 3. Moisturizer       │          │ 3. PDRN SERUM (2–3 drops) │
│ 4. SPF 30+           │          │ 4. Barrier moisturizer    │
└──────────────────────┘          │ 5. Occlusive (optional)   │
                                   └──────────────────────────┘
```

**Application rules:**

- Apply to **slightly damp** skin (except SPF, which goes on dry skin)
- **Pat and press**, don't rub — friction is irritation
- Wait ~30–60 seconds between layers so each one settles
- **2–3 drops** of PDRN is enough for the whole face. More is not better.

| **PM (week 4+)** | **PDRN** | **PDRN** | **PDRN** | Barrier | **PDRN** | **PDRN** | Barrier |

**"Barrier only" night** = cleanse → tone (optional) → moisturizer → occlusive. No PDRN, no actives.

*Why a rest day? Skin repair happens during recovery. Back-to-back actives without a rest night is where most people overdo it.*

## The evening buffers (for sensitive skin)

If PDRN ever tingles more than a mild 10-second tingle:

- **Buffer 1:** PDRN *after* moisturizer instead of before (slows absorption)
- **Buffer 2:** mix 1 drop PDRN into your moisturizer in your palm
- **Buffer 3:** short-contact — apply, leave 5 min, then layer moisturizer over

If it still stings: your barrier isn't ready. Go back to Phase 1 Reset.

## The do-not-mix rules (memorize these)

| Never combine on the same night | Why |
|--------------------------------|-----|
| **PDRN + exfoliating acid** (glycolic, lactic, salicylic) | Acid opens + irritates; PDRN then floods an inflamed barrier |
| **PDRN + retinol / retinal** | Both drive cell turnover signals — too much at once |
| **PDRN + high-dose vitamin C (L-ascorbic)** | pH clash, irritation risk |
| **PDRN + vitamin A *and* acid** | Triple active — barrier meltdown |
| **PDRN + physical scrubs / tools** | Micro-tears + actives = redness |
| **PDRN + clay mask** | Stripping + active = reactive |
| **PDRN immediately before SPF (AM)** | Saves nothing; keep PDRN for PM |

**Same-night stacks that ARE fine:**

- ✅ PDRN + hydrating toner/essence
- ✅ PDRN + hyaluronic acid
- ✅ PDRN + niacinamide (2–5%)
- ✅ PDRN + panthenol / centella / madecassoside
- ✅ PDRN + ceramide moisturizer
- ✅ PDRN + occlusive

## The "one active per night" principle

If you use multiple actives, give each its own night:

- **Monday** — PDRN
- **Tuesday** — PDRN
- **Wednesday** — Barrier only
- **Thursday** — Retinol (if you use it)
- **Friday** — PDRN
- **Saturday** — Barrier only
- **Sunday** — Gentle acid (1× week max, only if barrier score 8+)

This is the single most effective change you can make. It removes the guesswork from "what broke me out."

## Travel & minimal-routine version

When you can only carry three things:

1. **Gentle cleanser** (or micellar + rinse)
2. **PDRN serum** (multi-tasking hydrator + active)
3. **Barrier cream** (moisturizer + occlusive in one)

Add a **stick SPF** for the day. That's a complete PDRN routine in a quart bag.
